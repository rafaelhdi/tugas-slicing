## 🚀 Fitur Utama
* **Desain Responsif:** Tampilan menyesuaikan secara otomatis pada layar *Mobile*, *Tablet*, dan *Desktop* menggunakan Media Queries CSS.
* **Plain CSS:** Seluruh gaya visual dibuat murni menggunakan CSS3 (Flexbox & Grid) tanpa pustaka seperti Bootstrap atau Tailwind CSS.
* **Fitur Manipulasi DOM (JavaScript):**
  * **Navigasi Mobile:** Menu responsif yang dapat dibuka-tutup pada layar seluler.
  * **Toggle Mode Gelap/Terang:** Mengubah tema warna seluruh halaman secara dinamis.
  * **Daftar Interaktif:** Menambah dan menghapus item daftar secara dinamis melalui DOM *event listener*.

---

## 🛠️ Teknologi yang Digunakan
* **HTML5:** Struktur utama halaman web.
* **CSS3:** Tata letak, variabel warna, media queries, dan animasi transisi.
* **JavaScript (ES6):** Logika manipulasi elemen DOM.
